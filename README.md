# YouListen

A browser extension that covers all video playback on YouTube. For people who like to listen to YouTube as background noise but often get distracted by video. Lightweight and 100% local.

## Install

1. Click **Code > Download ZIP** on GitHub and extract it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the folder containing `manifest.json`.
4. Pin YouListen and refresh YouTube.

Keep the extracted folder in place. Chrome loads the extension from it.

## Controls

- **Hide video:** off reveals video until tomorrow.
- **Thumbnail:** show a still thumbnail instead of a blank screen.
- **1W / 1M / ALL:** listening and watching totals, stored on your device.

Thumbnail images load from YouTube. Native picture-in-picture is not covered.

## Update

If you cloned the repo, run `git pull` in its folder. If you downloaded a ZIP, replace the files in the same installed folder.

Then click **Reload** at `chrome://extensions` and refresh YouTube.
